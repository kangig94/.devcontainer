# 사내 프록시 CA (커밋하지 않는다)

`*.crt` 는 `.gitignore` 로 제외된다. 사내 인프라 정보라 공개 레포에 올리지
않는다. 빌드하는 사람이 직접 여기에 놓는다.

## 왜 필요한가

사내망의 HTTPS 프록시(`10.112.1.184:8080`)가 TLS 를 가로채고 자체 CA 로
재서명한다. 그 CA 가 없으면 컨테이너 안에서 `pip` / `curl` / `git` 이
`certificate verify failed` 로 죽는다.

프록시를 쓰는지는 **호스트의 `~/.docker/config.json`** 이 정한다 (`proxies`
항목이 있으면 docker 가 컨테이너에 `http_proxy` 등을 주입한다). 이미지 자체에는
프록시 설정이 없다. 프록시 예외 PC 에서는 그 항목이 없어 직결로 나가고, 여기
넣은 CA 는 쓰이지 않는다 — 넣어 두어도 라우팅에는 영향이 없다.

## 넣는 법

PEM 형식 `.crt` 를 파일당 인증서 하나씩 이 디렉터리에 둔다.
`update-ca-certificates` 가 전부 시스템 번들로 합친다. 개수 제한은 없다.

없으면 빌드는 그대로 진행된다 — 프록시 없는 망에서는 필요 없기 때문이다.
